# Radio Console

Listen to any radio station world wide with penguin radio !! 
Using the RadioBrowser API we can harness the power of radio in a simple console :)

## Features

- Search `Radio Browser` stations by country or genre
- Numbered selection when multiple matches are found
- Station list playback with direct stream URLs
- In-console now-playing section with:
  - reactive wave animation
  - centered UI text
  - rotating intro colors
- Controls:
  - `Enter` -> stop playback and return to station list
  - `Q` -> go back to country/genre search

---

| Component | Value |

## Prerequisites

- Windows
- .NET SDK 10 or newer
- Internet connection

---

## Quick Start

```powershell
dotnet restore
dotnet run
```

---

## Usage

1. Run the app.
2. Enter a search term (`japan`, `rock`, `rap`, etc.).
3. Choose country/genre match numbers when prompted.
4. Confirm playback.
5. Choose a station number.
6. Use controls:
   - `Enter` to stop current station
   - `Q` to return to search menu

---

## Project Notes

- On startup, the app fetches and caches:
  - `countries.json`
  - `Genres.json`
- If you hit file lock build errors (`MSB3021`/`MSB3027`), stop any running `dotnet run` instance and rebuild.
- `CS1668` warning about `TA-Lib` path is environment-related and not required by this app.
